# stack-signal-2025-developer-trends
Stack Signal 2025: Developer Technology Trends Capstone
Project overview
Stack Signal 2025 is a data analyst capstone presentation about the technologies developers use today, the technologies they want to learn next, and the signals visible in a small job-posting and salary dataset.

The project combines:

The latest published Stack Overflow Developer Survey available for this analysis — the 2025 survey.
The IBM Skills Network Jobs API lab dataset containing 27,005 job records.
The IBM Skills Network Web Scraping lab salary table containing 10 programming languages.

The analysis is designed to answer a practical question:
'Which technology skills should a learner build first, and which skills may help them specialize next?'

The main conclusion is that learners should build a durable foundation in web technologies, SQL and relational databases, then use Python as an applied bridge into data, automation and AI. Rust, Go, Redis and deeper PostgreSQL work can follow as role-specific specialization.
